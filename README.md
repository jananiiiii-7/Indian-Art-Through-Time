## 🌟 Overview

**INDIAN ART THROUGH TIME** is a digital museum exhibition designed to explore 5,000 years of India's living artistic heritage—from the earliest Bronze Age urban sculptures of the Indus Valley to classical Gupta Buddhist canons, monumental South Indian Dravidian stone spires, imperial Chola bronzes, royal Mughal miniatures, and 20th-century modernist revivals.

Built with **KnightLab TimelineJS**, the application presents a seamless 5,000-year interactive timeline where each slide dynamically changes background colors to reflect its historical epoch, complete with high-resolution artwork imagery, detailed historical context, bulleted features, "Did You Know?" facts, and a modal facts inspector.

---

## ✨ Key Features

### 1. 📜 KnightLab TimelineJS Chronological Engine
- **5,000-Year Interactive Trajectory**: Spanning from **c. 2500 BCE (Indus Valley)** to **c. 1945 CE (Modern Bengal Revival)** across 8 distinct historical epochs.
- **Dynamic Era Background Color Transitions**: Smooth 60fps color shifts between slides matching each era's signature material and aesthetic:
  - 🏛️ *Title Slide*: Espresso Bronze (`#2E1C11`)
  - 🏺 *Indus Valley Civilization*: Warm Terracotta Earth (`#4A2616`)
  - 🦁 *Mauryan & Early Buddhist Art*: Ashokan Crimson Red (`#4D1818`)
  - 🌸 *Gupta / Classical Art*: Classical Gold Ochre (`#593E0E`)
  - 🌿 *Early Medieval & South Indian Art*: Granite Emerald Green (`#123829`)
  - 🛕 *Medieval / Temple & Regional Art*: Chola Sandstone (`#5C2814`)
  - 🎨 *Mughal & Regional Painting*: Lapis Lazuli Royal Blue (`#122942`)
  - 📜 *Colonial / 19th-Century Art*: Mahogany Sepia (`#382314`)
  - 🎭 *Modern & Contemporary Art*: Indigo Violet (`#261838`)
- **Grouped Scrubber Axis**: Chronological timeline scrubber grouping events into historical periods for fast navigation and zoom.

### 2. 🔍 Detailed Exhibit Facts Inspector Modal
- Clicking **"❖ Inspect All Facts"** on any timeline slide opens an overlay displaying:
  - 🏛️ **Metadata Specs**: Art Form, Material/Medium, Technique, Dynasty/School, Current Location, and Accession Credit.
  - 📜 **Historical Context**: Comprehensive archaeological context and historical background.
  - 🔍 **Look Closer**: 3 highlighted visual details to inspect on the masterpiece.
  - 💡 **Did You Know?**: Intriguing historical trivia and facts.

### 3. 🎨 100% Emoji-Free Classic Museum Aesthetic
- Classical typography (*Cinzel Decorative*, *Cinzel*, *Cormorant Garamond*), gilded gold borders (`#C59B27`), and subtle ornament motifs (`❖`).

## 🚀 Local Development Setup

No build step, compilers, or npm packages required.

### 1. Clone the Repository
```bash
git clone https://github.com/jananiiii-7/Indian-Art-Through-Time.git
cd Indian-Art-Through-Time
```

### 2. Launch Local Server
```bash
python3 -m http.server 8080
```

### 3. Access in Browser
Open `http://localhost:8080` in your web browser.
