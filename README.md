# 🏛️ INDIAN ART THROUGH TIME
### *A Journey Through Art, Mythology, Culture and Craftsmanship Across India*

> **National Digital Museum & Interactive Heritage Exhibition**  
> Spanning 5,000 Years of Indian Artistic Heritage (c. 2500 BCE – 1950s CE)

---

## 🌟 Overview

**INDIAN ART THROUGH TIME** is a digital museum website designed to showcase five millennia of India's rich artistic traditions, monumental architecture, epic mythology, and indigenous craftsmanship.

Created with a classic art gallery aesthetic—featuring gilded gold leaf borders, mahogany accents, antique parchment backgrounds, and refined serif typography—this application provides an immersive experience for art historians, students, and museum enthusiasts.

---

## ✨ Key Features

### 1. 📜 Chronological Gallery Exhibition
- **8 Historical Eras**: Spanning from the **Indus Valley Civilization (c. 2500 BCE)** to **Modern & Contemporary Indian Art (c. 1950s CE)**.
- **22 Curated Masterpieces**: Complete dataset featuring high-resolution artwork images, historical context, material details, and "Look Closer" feature breakdowns.
- **Illuminated Era Headers**: Grand historical banners detailing artistic characteristics, patrons, and materials for each epoch.

### 2. 🗺️ Interactive OpenStreetMap Cartography
- **Powered by OpenStreetMap & Leaflet**: 100% free, open-source cartography with **zero API key requirements**.
- **10 Landmark GPS Monument Pins**: Real geographic coordinates for landmark art centers:
  - 📍 *Mamallapuram* (Pancha Rathas & Shore Temple, Tamil Nadu)
  - 📍 *Thanjavur* (Chola Bronze Nataraja & Brihadisvara, Tamil Nadu)
  - 📍 *Ajanta Caves* (Bodhisattva Padmapani Murals, Maharashtra)
  - 📍 *Ellora Caves* (Kailasa Monolithic Temple, Maharashtra)
  - 📍 *Sanchi* (Great Stupa & Gateway Reliefs, Madhya Pradesh)
  - 📍 *Khajuraho* (Kandariya Mahadeva Temple, Madhya Pradesh)
  - 📍 *Sarnath* (Gupta Preaching Buddha, Uttar Pradesh)
  - 📍 *Deogarh* (Dashavatara Temple, Uttar Pradesh)
  - 📍 *Udaipur* (Mewar Rajput Mahabharata Miniatures, Rajasthan)
  - 📍 *Kolkata* (Jamini Roy Bengal Folk Tempera Studio, West Bengal)
- **Interactive Popup Cards**: Click any monument pin to view an artwork thumbnail preview, title, date range, and 1-click exhibit inspection button.

### 3. 🔱 Tamil Nadu Special Exhibition Pathway
- **1,500-Year Trajectory**: Explores Tamil Nadu's unique artistic contributions:
  - *Stage I*: Pallava Rock-Cut Shrines (Mamallapuram)
  - *Stage II*: Structural Granite Temples (Shore Temple & Brihadisvara)
  - *Stage III*: Lost-Wax Chola Bronzes (Shiva Nataraja)
  - *Stage IV*: Thanjavur Gold Leaf & Gem-Inlaid Panel Paintings

### 4. 📜 Mahabharata Epic Narrative Thread
- **Recurring Mythological Theme**: Traces epic storytelling across diverse mediums and regions without overpowering the broader art history:
  - *Arjuna's Penance* (Granite Open-Air Relief, Mamallapuram)
  - *Krishna & Arjuna in the Bhagavad Gita* (Mewar Court Miniature Painting, Rajasthan)
  - *Akbar's Razmnama Illustration* (Mughal Royal Manuscript Painting)

### 5. 🔬 Comparative Masterpiece Analysis
- **Side-by-Side Art Viewer**: Compare artistic techniques and regional styles:
  - *Sarnath Gupta Buddha vs. Ajanta Murals*
  - *Pancha Rathas Monoliths vs. Khajuraho Nagara Temples*
  - *Chola Bronzes vs. Thanjavur Gold Leaf Painting*
  - *Mudra Hand Gestures & Iconography*

### 6. 🔍 Multi-Attribute Catalog Filter Engine
- Filter exhibit cards dynamically by:
  - **Historical Era** (8 Epochs)
  - **Geographic Region** (North, South, West, Central, East)
  - **Medium & Art Form** (Sculpture, Painting, Architecture, Seals, Manuscript, Bronzes)
  - **Thematic Thread** (Mythology, Religion, Power, Nature, Human Form, Storytelling)
  - **Quick Toggles**: *Tamil Nadu Tradition* & *Mahabharata Thread*

## 🚀 Quick Start & Installation

No external build tools or complex npm dependencies are required. The project is built using native web technologies and includes local asset fallbacks.

### 1. Clone or Download the Workspace
Navigate to the directory:
```bash
cd "/Users/jananisreed/Desktop/indian art form"
```

### 2. Launch Local Web Server
Run Python's built-in HTTP server:
```bash
python3 -m http.server 8080
```

### 3. Open in Browser
Visit the application at:
👉 **`http://localhost:8080`**
